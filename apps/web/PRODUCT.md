# Stampp

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Individual contributors tracking their own time and workspace owners managing a team are equally important.

## Product purpose

Stampp is an open-source work-time platform. People record time against work, while workspace owners manage projects, teams, approvals, and related operations.

## Positioning

The product has no seat pricing or feature gates and can be self-hosted.

## Operating context

The web app has a public entry, account creation and sign-in, a workspace picker, and an authenticated workspace. The workspace includes a timer, timesheets, attendance, schedules, projects, team management, reports, and administration.

## Capabilities and constraints

Keep existing routes and feature behavior during this UI refactor. The app uses Nuxt 4, Vue 3, Nuxt UI, and Vite+.

## Brand commitments

The name is Stampp. The current interface uses Geist, zinc neutrals, and an emerald primary color.
