# UI refactor snapshots

Captured on 26 September 2026 from a local review workspace with sample data. These images cover every page in the app. Longer pages have additional middle or bottom views, so the content below the first screen is available for PR review.

Desktop captures use a 1280 × 800 viewport; phone captures use a 390 × 844 viewport. The main set uses dark mode. Light mode examples are included for the landing page, timesheet, reports, and team.
